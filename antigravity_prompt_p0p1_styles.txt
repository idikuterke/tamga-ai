## İŞ 1 (P0) — `carved` maskesinin binarizasyon bug'ı
Dosya: `render.py`, satır 466–480

### Sorun
```python
carve_mask_arr = np.where(carve_mask_arr > 100, 255, 0).astype(np.uint8)
```
Bu satır maskeyi binary 0/255'e çeviriyor. Anti-aliased yumuşak kenar kayboluyor, line 672–700'deki inner bevel (subtract operasyonu) bu binary maske üzerinde çalışınca "damga gibi" pixelated bir görüntü çıkıyor — gerçek oyuk/kazıma hissi değil.

### Yapılacak
1. Binarizasyonu tamamen kaldır (`np.where > 100, 255, 0` satırını sil).
2. Anti-aliased maskeyi koru, sadece `mask_arr * np.array(chip_img)` ile yumuşak kenarlı "chisel micro-chipping" varyasyonunu uygula.
3. Inner bevel kodunu (line 672–700) binarize'siz maske üzerinde çalışacak şekilde yeniden yaz:
   - `inner_sh = max(0, mask - shifted)` yerine GaussianBlur'lu yumuşak fark: `inner_sh = ImageChops.subtract(mask, shifted).filter(ImageFilter.GaussianBlur(radius=blur_r))` (mevcut yöntem aslında doğru, sadece binarize'siz maske üstünde çalışsın)
   - `inner_hi` için aynı yaklaşım.
   - Offset ve blur değerleri Yol B'ye uygun kalsın: `offset = max(2, int(font_size * 0.04))`, `blur_r = max(0.8, font_size * 0.012)`.
4. Sonuç: carved harflerin kenarları yumuşak oyuk (inner shadow) hissi versin, pixelated damga gibi değil.

## İŞ 2 (P0) — 4 zayıf stilin baştan yazılması
Dosya: `render.py`, ilgili bloklar

### 2.1 `chalk` (satır 482–500) — gerçek tebeşir/kömür
- Maske üzerinde küçük bir morphological erosion (1-2px binary kernel ile `mask_arr < threshold` maskelenmiş pikselleri sıfırla) uygula — harf içi mikro boşluklar açsın
- Tozumsu kenar için: önce `GaussianBlur(radius=font_size*0.012)`, sonra orijinal maske ile `np.minimum(blurred, mask)` — sadece dış kenarlar tozumsu dağılsın, iç dolu kalsın
- Yüksek frekanslı powder noise (font_size'a orantılı çözünürlük: `int(canvas_h / max(2.0, font_size*0.05))`) ile grenli doku
- Final maske: anti-aliased kalsın, binary yapma
- Renk paleti: mevcut `(216, 212, 200)` kalsın (kullanıcı yine override edebilir)

### 2.2 `ember` (satır 601–626) — gerçek kor/ateş
- Mevcut tek-katmanlı outer glow yerine ÇOK KATMANLI (3 ayrı katman, 3 farklı yarıçap + 3 farklı renk):
  - Dış: `glow_r = max(4.0, font_size*0.08)`, renk `(180, 30, 0)`, alpha 140
  - Orta: `glow_r = max(2.0, font_size*0.04)`, renk `(255, 120, 20)`, alpha 180
  - İç: `glow_r = max(1.0, font_size*0.02)`, renk `(255, 220, 120)`, alpha 200
- Center weight formülünü düzelt (kenar koyu kırmızı, merkez parlak sarı-beyaz olmalı):
  - `emb_r = np.clip(fg_r * 0.25 + center_weight * (255 - 60), 0, 255)`
  - `emb_g = np.clip(fg_g * 0.10 + center_weight * (220 - 60), 0, 255)`
  - `emb_b = np.clip(fg_b * 0.05 + center_weight * (140 - 60), 0, 255)`
  - Bu sayede kenarda `(64, 18, 3)` koyu kırmızı, merkezde `(255, 220, 140)` parlak sarı çıkar
- Her katman font_size'a orantılı

### 2.3 `ash` (satır 502–522) — gerçek kül
- Çatlak eşiği `abs(noise - 0.5) < 0.025` çok dar. Genişlet: `abs(noise - 0.5) < 0.06` (yaklaşık %12 coverage)
- Çatlak çözünürlüğünü yükselt: `int(canvas_h / max(2.0, font_size*0.15))` → `int(canvas_h / max(2.0, font_size*0.35))` (örn. canvas_h=512, font_size=256 için ~35 satır)
- Noise pattern'i sadece dikey değil, 3 farklı açıda (0°, 60°, 120°) çatlak üret:
  - `crack_y = Y_st * np.cos(θ) + X_st * np.sin(θ)` (her θ için ayrı noise grid'i)
  - Üçünü birleştir: `crack_combined = np.minimum.reduce([crack_0, crack_60, crack_120])`
- Yumuşak halo: outer alpha bleed için `mask.filter(GaussianBlur(font_size*0.03))` ile sönük dış katman
- Mevcut fading edge mantığı korunsun

### 2.4 `stencil` (satır 524–540) — gerçek ızgara delikleri
- Mevcut `(Y % period_y < gap_y) & (X % period_x*1.5 > period_x*0.5)` yatay bant üretiyor. **Sil.**
- Yerine gerçek küçük uniform delikler ızgarası:
  - Period: `period_x = max(8.0, font_size * 0.18)`, `period_y = max(8.0, font_size * 0.22)`
  - Gap: `gap_x = max(2.0, font_size * 0.04)`, `gap_y = max(2.0, font_size * 0.05)`
  - Kare delik kesimi:
    ```python
    cut = ((X_st % period_x) < gap_x) | ((Y_st % period_y) < gap_y)
    stencil_mask = ~cut
    ```
  - VEYA yuvarlak delik için mesafe yöntemi: her deliğin merkezinden `sqrt(dx^2 + dy^2) < delik_yarıçapı` → kesilmiş
- Stencil'in doğası gereği kesilmiş yerler 0 olur (binary OK burada), ama ana maske `mask * stencil_mask` ile alpha compositing yapılsın, böylece harf dışı 0 kalır
- Sonuç: küçük nokta delikleriyle kaplı harfler (gerçek sprey boya şablonu hissi)

## İŞ 4 (P1) — UI: "Lock custom color" toggle
Dosya: `static/index.html`, satır 432–441 (`resetTextColor` fonksiyonu) ve satır 442–469 (`renderStyle` change listener)

### Sorun
Kullanıcı custom renk seçtiğinde stil değiştirince `resetTextColor` çağrılıp renk stilin varsayılanına dönüyor. Kullanıcı özel rengini kaybediyor.

### Yapılacak
1. HTML'e `renderTextColor` kutusunun yanına küçük bir 🔒 toggle button ekle (kilitli/serbest iki durum, default kilitli=false yani mevcut davranış).
2. JS state: `let lockCustomColor = false;` global.
3. `renderStyle` change handler'ı güncelle:
   ```javascript
   document.getElementById('renderStyle').addEventListener('change', () => {
     const colorInput = document.getElementById('renderTextColor');
     if (colorInput && colorInput.dataset.custom === 'true' && !lockCustomColor) {
       resetTextColor();
     }
     // ... mevcut styleSuggestions kodu
   });
   ```
4. Lock toggle tıklanınca:
   - `lockCustomColor = !lockCustomColor`
   - Buton ikonu: 🔒 (kilidi) veya 🔓 (serbest)
   - Buton başlığı (title): "Özel rengi kilitle" / "Özel renk kilidini aç"
   - `handleRender` payload'unda text_color zaten custom=true ise gönderiliyor, bu davranış değişmesin
