## Temel Prensip — "Letter-First" (YENİ KURAL)
**Hiçbir stil harfin merkez kütlesini (mask alpha > 200 bölgesi) %30'dan fazla azaltmasın. Erosion kenarda, glow üstte, çatlak yüzeyde olsun — gövde korunacak.**

Bu kural tüm düzeltmelerde temel alınacak.

## İŞ 1 — `chalk` Düzeltmesi (Görünürlük)

### Mevcut Sorun
Q1-Q3'teki morfolojik erosion harfin **gövdesinde** delik açıyor. Erosion kernel harfin iç bölgelerinde de çalışıyor → harf parçalanmış görünüyor.

### Yapılacak
Erosion'ı sadece **maskenin dış kenarında** uygula, gövdeye dokunma:
```python
# Mevcut erosion bloğunu şu mantıkla değiştir:
eroded_mask = mask_arr < threshold  # en dış kenarlar (alpha düşük)
mask_safe = mask_arr.copy()
mask_safe[eroded_mask] = 0  # sadece dış kenarda sıfırla
# GÖVDE KORUMASI (Letter-First):
mask_safe[mask_arr > 150] = mask_arr[mask_arr > 150]  # gövdede ASLA sıfırlama
```

Toz noise (P1'deki) ve edge dust / drop shadow (Q1-Q3'teki) olduğu gibi kalsın.

### Kabul Kriteri
- Harf gövdesinin en az %70'i tam alpha (255) yoğunluğunda olmalı.
- Sadece dış kenarda tozumsu boşluklar görünmeli.

## İŞ 2 — `ember` Düzeltmesi (Renk Kimliği)

### Mevcut Sorun
Q1-Q3'te eklenen 4. katman (hot white core) harfin fg rengini (turuncu) yutuyor, beyaz ışık küre gibi görünüyor. `center_weight` formülü de beyaz tonu fazla parlak yapıyor.

### Yapılacak
1. **L4 hot white core'u tamamen kaldır.** Hot core sadece harfi renksizleştiriyor, estetik katmıyor.
2. L1, L2, L3 (outer halo, middle glow, inner core gradient) Q1-Q3 haliyle kalsın.
3. Inner core gradient formülünde `center_weight` değerlerini kontrol et — merkez çok parlaksa alpha değerlerini 0.85 ile çarp:
   ```python
   # Mevcut emb_r hesabı (Q1-Q3 sonrası):
   # emb_r = np.clip(fg_r * 0.25 + center_weight * (255 - 60), 0, 255)
   # Üst sınırı ekle (max 240, saf beyaz olmasın):
   emb_r = np.clip(fg_r * 0.25 + center_weight * (240 - 60), 0, 255)
   # Aynısı g ve b için de:
   emb_g = np.clip(fg_g * 0.10 + center_weight * (220 - 60), 0, 255)
   emb_b = np.clip(fg_b * 0.05 + center_weight * (140 - 60), 0, 255)
   ```
4. Default fg_color `(255, 180, 50)` korunmalı, beyaz ton override etmemeli.

### Kabul Kriteri
- Harf turuncu rengini korumalı, beyaz ışık küre gibi görünmemeli.
- Avg RGB ölçümünde R > 200, G > 100, B < 100 (turuncu) aralığında olmalı.

## İŞ 3 — `ash` Düzeltmesi (Çatlak Sınırlaması)

### Mevcut Sorun
Çatlaklar harfin **gövdesinden** geçiyor, macro-fading harfi eritiyor. Çatlak pattern'i tüm maske üzerinde uygulanıyor.

### Yapılacak
1. **Çatlaklar sadece yüzeyde** olsun, gövdede olmasın:
   ```python
   # Çatlak maskesi sadece alpha 100-200 aralığında aktif (gövde dışı + kenar)
   surface_mask = (mask_arr >= 100) & (mask_arr <= 200)
   # Gövde (alpha > 200) dokunulmaz kalır:
   body_mask = mask_arr > 200
   # Çatlak sadece surface'e uygulanır:
   ash_with_cracks = mask_arr.copy()
   ash_with_cracks[surface_mask] = mask_arr[surface_mask] * crack_intensity
   # body_mask zaten korunuyor (koşul yüzünden)
   ```
2. **Macro-fading bloğunu ciddi şekilde zayıflat:**
   - `blur_ash = max(1.0, font_size * 0.025)` → `blur_ash = max(0.5, font_size * 0.008)` (3x küçült)
   - VEYA bloğu tamamen kaldır (Q1-Q3 öncesi haline dön), sadece dust halo (L4) kalsın
3. Dust halo (Q1-Q3'teki L4) olduğu gibi kalsın — harfin DIŞINDA halo vermesi doğru, gövdeye dokunmuyor.

### Kabul Kriteri
- Harf gövdesi en az %70 alpha yoğunluğunda olmalı.
- Çatlaklar sadece harfin yüzeyinde (kenarlara yakın) görünmeli, gövde içinden geçmemeli.

## İŞ 4 — `stamp` GERİ DÖNÜŞÜ (P0 Haline)

### Mevcut Sorun
Q1-Q3'te eklenen L3 "edge wear (1-2px border erosion, %20 alpha düşüşü)" orijinal stamp stilini bozdu. Harf "solmuş" görünüyor. P0 sonrası + Q1-Q3 öncesi hali (sadece pressure + grunge) daha iyiydi.

### Yapılacak
1. **L3 edge wear bloğunu tamamen kaldır.** Q1-Q3 öncesi P0 haline geri dön.
2. **Sadece L1 (pressure variation) + L2 (grunge holes) kalsın.** Bunlar P0'da vardı ve iyi çalışıyordu.
3. **stamp_var="rot" ve stamp_var="grunge" varyantları** mevcut haliyle (P0) korunsun, hiçbir değişiklik yapılmasın.
4. **Rotasyon açısı** (-1.5 ila 1.5 derece, veya rot varyantında 4-5 derece) korunsun.
5. **Grunge threshold'ları** (0.6, 0.8, 1.2 vs.) korunsun.

### Kabul Kriteri
- Stamp harfi orijinal (P0 sonrası) haline dönmeli: basınç değişimi + grunge delikleri var, ama kenarda solma yok.
- `stamp_var="rot"` ve `stamp_var="grunge"` çağrıları orijinal davranışla çalışmalı.
- Harf gövdesi en az %70 alpha yoğunluğunda olmalı.

---

## İŞ 5 — `stencil` Düzeltmesi (Delik Sıklığı)

### Mevcut Sorun
Gerçek ızgara delikleri çok sık. Harfin %30-40'ı delik, "harf" değil "delik deseni" gibi görünüyor. Drop shadow da kontrastı artırıp delikleri daha belirgin yapıyor.

### Yapılacak
1. **Period'u ~2x büyüt (daha az delik):**
   - `period_x = max(8.0, font_size * 0.18)` → `period_x = max(12.0, font_size * 0.36)`
   - `period_y = max(8.0, font_size * 0.22)` → `period_y = max(12.0, font_size * 0.44)`
2. **Gap'i biraz küçült (delikler daha küçük):**
   - `gap_x = max(2.0, font_size * 0.04)` → `gap_x = max(1.5, font_size * 0.03)`
   - `gap_y = max(2.0, font_size * 0.05)` → `gap_y = max(1.5, font_size * 0.035)`
3. **Drop shadow'u kaldır.** Harf zaten kontrastlı (kesik alanlar), gölge delikleri daha belirgin yapıp harf bütünlüğünü bozuyor.
4. Sadece delik kesimi kalsın (Q1-Q3 haliyle), diğer mantık aynı.

### Kabul Kriteri
- Harf gövdesinin en az %85'i boşluksuz olmalı, sadece küçük stencil delikleri (toplam %10-15) görünmeli.
- Harf hâlâ "stencil" gibi okunmalı ama "delik deseni" gibi değil.

## İŞ 6 — `neon` Geri Dönüşü + Vitrin

### Mevcut Sorun
Q1-Q3'te L3 "bright white core" eklendi, neon'un kimliği (siyah arka plan + cyan parlak yazı) bozuldu. Beyaz core yazının kendisini renksizleştirdi.

### Yapılacak
1. **L3 bright white core'u tamamen kaldır.** Q1-Q3 öncesi 2-katmanlı hale dön.
2. **L1 outer halo + L2 middle bloom** (mevcut) korunsun.
3. **Style dict'inde** `neon` için `fg=(0, 255, 200)` (cyan) ve `bg=(10, 10, 30)` (koyu lacivert) doğrula, değiştirme.
4. **`STYLES["neon"]` zaten var** — yeni ekleme yok, sadece L3 kaldırılacak.
5. **Vitrin stili olarak öne çıkar:**
   - `static/index.html`'deki `renderStyle` dropdown'ında neon'u **ilk sıraya** taşı.
   - Neon için `textureSuggestionHint`'te vitrin mesajı:
     - Şu an: `"💡 Öneri: Düz Arka Plan (veya alternatif: Neon Işık / Taş)"`
     - Yeni: neon seçildiğinde `"🌟 Vitrin Stili — yüksek kontrast, karanlık arka plan"`
   - `resetTextColor` defaults sözlüğünde neon zaten var, kontrol et.

### Kabul Kriteri
- Neon orijinal kimliğine dönmeli: siyah arka plan, cyan parlak yazı, glow etrafında.
- Harf avg RGB ölçümünde cyan tonu (R < 100, G > 200, B > 150) aralığında olmalı.
- UI dropdown'ında neon ilk sırada görünmeli.

### 3. Otomatik görsel kabul kriteri (Letter-First Doğrulaması)
Her test PNG için harf gövdesinin ortalama alpha yoğunluğunu ölç:
```bash
python -c "
from PIL import Image
import numpy as np
results = []
for style in ['chalk', 'ember', 'ash', 'stamp', 'stencil', 'neon']:
    img = np.array(Image.open(f'test_p2_{style}.png').convert('L'))
    letter_mask = img > 50
    if letter_mask.sum() > 0:
        avg_alpha = img[letter_mask].mean()
        coverage = letter_mask.sum() / img.size * 100
        results.append((style, avg_alpha, coverage))
        print(f'{style}: avg_alpha={avg_alpha:.1f}, coverage={coverage:.1f}% (target: avg>180, coverage>5%)')
# Tüm avg_alpha > 180 olmalı, yoksa hangisi başarısız rapor et
failed = [r for r in results if r[1] < 180]
if failed:
    print(f'FAILED: {failed}')
else:
    print('ALL STYLES PASS letter-first check!')
"
```

**Hedef:** Tüm 6 stil için `avg_alpha > 180` (gövde en az %70 yoğunlukta).
